# TalentCore
## Sistema de Gestión de Empleados y Solicitudes de Vacaciones

### Descripción del proyecto

TalentCore es un proyecto académico de desarrollo de software que permite administrar información de empleados y gestionar solicitudes de vacaciones mediante una API REST.

El proyecto se desarrolló aplicando las etapas del ciclo de vida del desarrollo de software (SDLC), con apoyo de agentes de inteligencia artificial especializados en diferentes funciones.

### Objetivo general

Desarrollar un sistema que facilite el registro, consulta, actualización y eliminación de empleados, así como la administración y seguimiento de solicitudes de vacaciones.

### Tecnologías utilizadas

- **Python:** lenguaje de programación.
- **FastAPI:** desarrollo de la API REST.
- **SQLite:** almacenamiento de datos.
- **Pydantic:** validación y definición de modelos de datos.
- **Pytest:** ejecución de pruebas automatizadas.
- **Groq y modelos de IA:** apoyo a los agentes del proyecto.
- **Git y GitHub:** control de versiones y almacenamiento del código.
- **Visual Studio Code:** entorno de desarrollo.

### Funcionalidades implementadas

- Registro y consulta de empleados.
- Actualización y eliminación de empleados.
- Registro de solicitudes de vacaciones.
- Consulta del historial de vacaciones.
- Aprobación y rechazo de solicitudes.
- Cálculo de días solicitados.
- Endpoint de verificación del estado del sistema.

### Agentes de inteligencia artificial

Durante el proyecto se trabajó con agentes especializados en:

1. **Product Owner:** análisis y documentación de requisitos.
2. **Arquitecto:** diseño de la arquitectura del sistema.
3. **Desarrollador:** implementación del backend.
4. **QA:** análisis y pruebas de calidad.
5. **Seguridad:** revisión de riesgos y vulnerabilidades.
6. **DevOps:** documentación y preparación para el despliegue.

### Pruebas

Se ejecutaron pruebas automatizadas con Pytest, obteniendo 12 pruebas aprobadas. También se realizaron pruebas de los endpoints mediante la documentación interactiva de FastAPI.

### Documentación

Este repositorio incluye documentos relacionados con los requisitos, arquitectura, implementación, calidad, seguridad y DevOps.

### Estado del proyecto

El backend funcional y las pruebas básicas se han desarrollado. Permanecen pendientes mejoras de seguridad y la validación del despliegue en contenedores.
